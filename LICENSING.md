# Licensing Scope

This file states the repository-level application of the license texts. A more
specific file-level copyright or license notice controls when present.

| Scope | SPDX identifier | License text |
| --- | --- | --- |
| Original root tooling, documentation, and bridge software | `AGPL-3.0-or-later` | [`LICENSE`](LICENSE) |
| Original firmware software under `firmware/` | `GPL-3.0-or-later` | [`firmware/LICENSE`](firmware/LICENSE) |
| Future original hardware/CAD/source-design files | `CERN-OHL-S-2.0` | To be included with those files |

No original hardware/CAD/source-design files are currently present, so no empty
CERN-OHL-S scope or license file is added. Third-party Waveshare hardware,
documentation, reference designs, and other third-party material are not covered
by that future designation.

Third-party components and assets retain their upstream terms. Their notices must
be preserved, including the Adafruit BSD notice described in
[`firmware/THIRD_PARTY_NOTICES.md`](firmware/THIRD_PARTY_NOTICES.md).

The `-or-later` designations mean recipients may use version 3 of the applicable
GNU license or, at their option, any later version published by the Free Software
Foundation. Separately negotiated proprietary exceptions may be available as
described in [commercial licensing](COMMERCIAL-LICENSING.md).

This scope statement is not legal advice. Obtain qualified counsel before
commercial reliance or combining the software with differently licensed works.
